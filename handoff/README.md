# Using this project from another computer or assistant

1. Read PROJECT_HANDOFF.md and ../BUILD_GUIDELINES.md.
2. For coding, extract the full project ZIP and either open source/ or clone
   manga-downloader.bundle into a new directory.
3. In ChatGPT Desktop, create a Project named "Manga Downloader - Series Folders".
   Add PROJECT_HANDOFF.md, BUILD_GUIDELINES.md, PROJECT_INSTRUCTIONS.md and the
   project ZIP. Paste PROJECT_INSTRUCTIONS.md into Project instructions if desired.
4. Tell the assistant to continue from the handoff and obey the narrow scope.
5. A connected Drive account may let another chat find these files, but no
   assistant has automatic access merely because a Drive folder exists. If ZIP
   contents are not readable in that chat, attach/extract the relevant full files.

Status: scope-only project. No Series Folders or Guess Language code, custom
Windows executable or installed toolchain is included yet. Existing upstream
source and legacy working extension are included for continuity. The Git bundle
preserves local commits. There are no account tokens or downloaded manga images.

A ChatGPT Project has not been created automatically. These are portable project
files, intentionally usable with other tools too. Sharing with another person
still requires granting them access or sending them a copy.
