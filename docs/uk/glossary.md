# Глосарій українського інтерфейсу

Терміни, якими користуються українські тексти програми
(`gui/frontend/src/locales/uk/`) і [посібник](app.md). Кожен рядок:
англійський термін, український відповідник, коротке пояснення вибору.
Новий текст у каталозі має вживати саме ці слова.

## Основні поняття

- chapter: розділ — як на українських сайтах манґи (zenko та інші); не «глава».
- volume: том
- part (of a chapter): частина
- series: серія — один твір на сайті з усіма його розділами.
- title (a work): твір — у «[Для дорослих]», «Твір для дорослих».
- site: сайт
- page: сторінка
- file: файл
- folder: папка — як у Windows українською; не «тека».
- Recycle Bin: Кошик — назва в українській Windows; на macOS і Linux у посібнику — Смітник.
- duplicate: дублікат; duplicate file: файл-дублікат
- scanlation group / scanlator: команда перекладу — як кажуть читачі; «скалейт» не вживаємо.
- language: мова
- link / URL: посилання — у полі «Посилання на серію»; «адреса» лише про адресу сайту.
- manga: манґа — з «ґ», як у видавців манґи українською.
- e-reader: електронна читалка, читалка
- bundle: пакет — «Один файл» у «Пакувати як»; «збірка» зайнята значенням «build».
- build (of the app): збірка — «Збірки для розробки».
- release (version): випуск
- log: журнал
- history: історія
- session: сеанс — «З минулого сеансу».
- queue: черга
- browser: браузер
- captcha: капча
- headless browser: браузер без вікна
- pop-up tab: спливна вкладка
- device secret (MangaPlus): ключ пристрою
- automatically: автоматично — не «саме», яке читається ще й як «саме так».
- Parts merged (button): цілими — «Завантажити 5 розділів цілими».
- section of the window: вкладка, група — «розділ» лише для chapter.

## Дії (кнопки)

- Load: Відкрити — відкриває серію і її список розділів; «Завантажити» залишено тільки для download.
- Loading…: Відкриття…
- Reload: Оновити
- Download: Завантажити
- Downloading: Завантаження (стан), завантажується (про розділ)
- Cancel: Скасувати
- Cancel all: Скасувати все
- Clear: Очистити
- Paste: Вставити
- Copy / Copied: Копіювати / Скопійовано
- Close: Закрити
- Dismiss: Сховати
- Browse…: Огляд…
- Delete: Видалити
- Restart: Перезапустити
- Retry / Try again: Спробувати ще раз
- Select all / Select none: Вибрати всі / Зняти вибір
- All / None: Усі / Жодного
- Fold / Unfold: Згорнути / Розгорнути
- Open folder: Відкрити папку
- Update now / Later: Оновити зараз / Пізніше
- Release notes: Що нового
- Skip: Пропускати (параметр), пропущено (результат)
- Pack / packing: пакувати / пакування
- Fetch: отримати — «Отримання сторінок…»

## Частини вікна

- Options (tab): Параметри — те, що має відповідник у командному рядку.
- Settings (dialog): Налаштування — лише для програми (мова, початковий екран, оновлення).
- Activity (tab): Активність
- Side panel: Бічна панель
- Status bar: рядок стану
- Start screen / simple view: Початковий екран / спрощений вигляд
- Advanced: Додатково
- Save (options group): Збереження
- Pages (options group): Сторінки
- Overall progress: Загальний прогрес
- tooltip / hint: підказка

## Назви параметрів

- Series folders: Папки для серій
- Guess language: Визначати мову
- Skip existing files: Пропускати наявні файли
- Age check / I am over: Перевірка віку / Мені вже виповнилося
- Format: Формат; Folder (raw images): Папка
- Reading direction: Напрямок читання; Right to left / Left to right: Справа наліво / Зліва направо
- Pack as: Пакувати як; Chapters / Merged / Volumes / One file: Розділи / Об’єднані / Томи / Один файл
- Convert to JPEG: Перетворювати на JPEG
- Compress pages: Стискати сторінки
- JPEG quality: Якість JPEG
- Skip pages: Пропускати сторінки
- Filename template: Шаблон назви файлу; default: типовий
- Show the browser window: Показувати вікно браузера
- Download N missing: Завантажити ще N — коротко, щоб кнопка вміщалася; підказка пояснює, що це відсутні розділи.
- Restart N unfinished: Перезапустити незавершені (N)
- Delete series: Видалити серію
- Adult title: [Для дорослих]
- VPN?: VPN? (без перекладу)

## Стани розділу

- done / saved: готово / збережено
- downloading: завантажується
- queued: у черзі; waiting: чекає, очікування
- failed: не вдалося, невдалий; помилка (у рядку завантаження)
- cancelled: скасовано
- missing: відсутній
- to do: чекає (у рядку), залишився / залишилося (у лічильниках)
- locked: заблокований

## Правила письма

- Числа з іменниками узгоджуються за чотирма формами множини
  (`_one`, `_few`, `_many`, `_other`): 1 розділ, 2 розділи, 5 розділів,
  1,5 розділу. Форма `_other` у нас лише для дробів, програма їх не показує.
- Де узгодження заважає (лічильники в один рядок), число стоїть першим
  («3 збережено», «2 у черзі») або після двокрапки («паралельно: 8»).
- Лапки — «ялинки»; апостроф — ’ (U+2019).
- Звертання на «ви», з малої літери; спокійний, нейтральний тон, без
  канцеляризмів.
- Стани процесу — віддієслівні іменники з трикрапкою: «Відкриття…»,
  «Пакування…».
- Без перекладу: Manga Downloader, CBZ, CBR, EPUB, AVIF, WebP, JPEG, Ko-fi,
  VPN, змінні шаблону (`{{series}}` тощо), приклади діапазонів (`1-10,12`),
  позначки мов (`[en]`, `[mul]`), назви клавіш Shift, Enter, Esc
  (але «Пробіл»).
- Що залишається англійською з інших причин (назви розділів, причини помилок
  від сайтів, розміри файлів, `log.txt`), описано наприкінці
  [посібника](app.md#що-залишається-англійською).
